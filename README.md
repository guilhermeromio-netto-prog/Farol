# Farol

Planejador de viagem. O briefing vira três roteiros, com clima, custo em reais, tempo e um checklist de partida.

A especificação completa para continuar o desenvolvimento está em [FAROL.md](FAROL.md).

## Rodar

```bash
npm install
npm run dev
```

A geração do roteiro precisa de `XAI_API_KEY` no servidor. A chave não entra neste repositório.
